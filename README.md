## ✨ 功能特性

- **多账号管理**：每个账号独立 Chrome 窗口，互不串号；支持 Excel / 文本批量导入导出
- **自动登录**：自动填账号密码、自动识别验证码，识别错误自动刷新重试
- **免费本地识别**：内置验证码识别模型，离线运行、不花钱、不限次（也支持 CapMonster / 2Captcha 云端识别）
- **安静值守**：登录成功后低频监测，掉线自动重登，降低触发风控的概率
- **定点抢报**：设定开抢时间，到点自动查询、自动勾选协议、自动填码提交，悬浮窗实时倒计时
- **参数内置**：常用设置已内置，删掉 exe 旁边的 `settings.json` / `accounts.json` 即可恢复出厂默认
- **安全发布**：识别模型以 AES-256 加密内置，程序原生编译，不依赖外部明文资源
- **数据本地化**：账号、设置全部保存在自己电脑上，不上传任何服务器

## 🚀 快速上手（5 步）

1. **添加账号**：左侧「账号管理」→ ➕ 添加账号（用户名 / 密码 / 省份）；
2. **填设置**：右侧 ⚙ 设置 → 填目标登录网址，识别服务选 `local`；
3. **保存设置**；
4. **启动**：选中账号 → ▶ 启动选中（多账号点 ▶ 启动全部）；
5. 日志出现「✅ 登录成功，进入后台静默监测」即已在值守。

需要定点开抢：右键账号 →「⏰ 定时设置1（定时查询）」→ 填入时间（格式 `2026:09:19:14:30:00`）。

## 📌 使用须知

- 需要电脑已安装 **Google Chrome** 官方正式版（驱动自动下载）；
- exe 请放在**普通可写文件夹**，不要放 `C:\Program Files` 或压缩包内直接运行；
- 定时抢报按**电脑系统时间**执行，开抢前务必校准时间；
- 升级：新 exe 直接覆盖旧 exe，`accounts.json` / `settings.json` / `browser_profiles\` 原样保留。
